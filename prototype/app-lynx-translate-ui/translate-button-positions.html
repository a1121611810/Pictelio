显示模式
翻译
③ FAB 与现有 GlobalFab 视觉风格一致；但要再叠加一个翻译 FAB + 一个模式切换 FAB
↳ 缺点：FAB 已用于章节切换；多层 FAB 干扰导航手势
设计要点（spec §6.2 收敛）
  • 顶部 banner：选择理由 = 一次性能同时呈现「翻译 + 显示模式切换」两个控件；FAB 不允许（GlobalFab 已被章节切换占用）。
  • 章节标题旁：缺点 = 标题区拥挤 + 双控件分散到不同 row，焦点不清晰；切换章节后控件位置跳变。
  • FAB：缺点 = 与现有 GlobalFab 重叠风险 + 多 FAB 堆叠违反 M3 single FAB 原则。
  • 翻译按钮 5 态：未译+有endpoint→「翻译」；未译+无 endpoint→「配置翻译」；已译→「重译」；翻译中→「翻译中 N%」；部分译→「续译」（自动，Q21）。
