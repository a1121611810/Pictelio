⚠ endpoint 不兼容
你的 endpoint https://openrouter.ai/api/v1 对 /v1/responses 返回 HTTP 404。 当前仅支持 OpenAI Responses API 协议（POST /v1/responses）。
兼容 Responses API 的服务
  • · OpenAI（gpt-5 / gpt-5-mini / gpt-5-nano）
  • · Azure OpenAI（deployment 名 + api-version: preview header）
  • · DeepSeek（Codex 兼容模式）
  • · vLLM 自托管（≥ 0.6.2）
常见不兼容服务
  • · OpenRouter / 智谱 GLM / 通义千问 / 文心千帆
  • · LocalAI / LM Studio / Ollama
③ Sheet（bottom） M3 modal bottom sheet；详细信息 + 兼容性矩阵列表 + 双 CTA
↳ 缺点：覆盖屏幕 70% 内容；首次失败即弹 modal 干扰阅读
设计要点（spec §6.4 + §9.1 收敛）
  • inline retry bar：阻塞态错误不能自动消失（spec §6.4 明确）；用户必须 retry 或更换 endpoint，切换章节后才清除。
  • 错误细节：展示 HTTP code + endpoint URL + 兼容/不兼容 provider 列表；「更换 endpoint」跳设置页。
  • Snackbar：仅适合非阻塞通知（自动消失）；阻塞错误会丢失上下文。
  • Sheet：信息密度高但首次失败即弹 modal 干扰阅读；适合「点 retry 失败后」二级诊断而非首次提示。
  • 正文区状态：inline retry bar 形态下，正文变灰（不可交互）+ 占位符「〔未翻译〕」（partial / failed 共用）。
