③ Icon toggle 用「あ / 中」字面 icon 表意源语言/目标语言；最紧凑但语义较弱
↳ 缺点：icon 含义需学习；首屏辨识度低
设计要点（spec §6.3 收敛）
  • segmented button：M3 推荐控件（spec §6.3）；lift-up indicator + secondary-container 高亮；切换瞬间无 loading（< 50ms 完成）。
  • 已缓存 chip：紧贴 segmented 右侧（Q20）；长按 segmented 区域可触发「重译」（避免误触）。
  • 顶部 tab：虽然辨识度强，但占整行 + 与 app-lynx 主导航 tab 同形，会被误以为是页面级导航。
  • icon toggle：最紧凑但首屏辨识度低，不适合「首次进入详情页就需用」的强提示场景。
