那是一个飘着细雨的夜晚。便利商店的自动门发出轻微的嗡嗡声，又一位顾客走了进来。

我抬起头，习惯性地说出「欢迎光临」。但进来的那个人没有看商品架，而是径直走向柜台。

她看上去二十岁出头，穿着一件淋湿的米色风衣，长发贴在脸颊上，眼神却异常平静。

「我在找一个东西，」她开口说，声音很轻，「一个很小的东西。」

我把目光从收银机上移开，第一次认真打量她的脸。

③ 浮层 chip（top-right） primary 色 chip + elevation 阴影；不参与 sticky 行布局
↳ 缺点：与 segmented 视觉竞争；与 app-bar 距离过近易误读
设计要点（spec §6.3 + §6.5 + Q20 收敛）
  • segmented 右侧：M3 tonal chip（primary-container 底）；长按 segmented 区域可触发「重译」快捷入口，避免误触。
  • 显示时机：仅在 status === 'completed' 且 fromCache === true 时显示；本次新译完成的瞬间不显示「已缓存」（缓存写入 done 包内部）。
  • 独立一行：可承载「上次更新 2 小时前」等扩展信息；缺点 = 多占首屏空间 + 与 segmented 割裂。
  • 浮层 chip：视觉最显眼，但与 segmented 形成双焦点；与 app-bar 距离近易误读为「导航状态」。
  • 未配置时的 fallback：当 LLM endpoint 未配置时，segmented 控件显示但 disabled；不显示「已缓存」标识。
