③ 校验失败态 base URL 输入框红边 + 错误描述 + probe chip 标 ⚠；保存按钮禁用
→ 决策：inline error + chip 联动（同一基线），不弹 modal
设计要点（spec §6.1 + §9.1 收敛）
  • 未配置引导：列表分组入口仅一行红字「未配置」；点开后才显示指引横幅（避免首屏认知负担）。
  • probe chip：M3 tonal chip（secondary / primary / error container 三档），紧贴 base URL 下方；debounce 600ms 探测 `/v1/responses`。
  • API Key 字段：password 类型 + 「显示」toggle 5s 后自动隐藏 + 「清空」icon button。
  • 校验失败 UX：inline 错误 + base URL 红边 2px；点「保存」按钮 disabled 而非弹错（清晰度 + 修正路径都给）。
  • 不提供 preset：无「OpenAI / DeepSeek / Azure」快捷按钮；遵守 Q3 完全从零 + Q5 不预设。
