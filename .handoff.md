# Pictelio — Handoff Document

## Context
Pixiv third-party client **Pictelio** (`a1121611810/pixivizer`). SolidJS 1.9 + Capacitor 8.4 Android app. Dev runs at `http://localhost:5173`.

## Summary of Work (completed in this session)

### 1. Store Splitting (T1-T2)
Monolithic stores → per-tab independent stores for instant CSS-display tab switching:
- `feedStore` → `recommendedStore` + `followStore`
- `novelStore` → `novelRecommendedStore` + `novelFollowStore` + `novelBookmarkStore`
- Shared helpers: `feedHelpers.ts`, `novelHelpers.ts`

### 2. Route Consolidation (T3-T4)
All 4 bottom tabs → single `/home` route. CSS `display: none/block` toggle:
- `HomePage.tsx` + `RecommendedFeed`, `FollowFeed`, `BookmarksFeed`, `HistoryFeed`
- Deleted old routes: `/recommended`, `/following`, `/bookmarks`, `/history`
- NavBar: in-page `replaceState` when on `/home`

### 3. Novel Decoupling (T5)
- `NovelFeedPage` → `NovelRecommendedFeed` + `NovelFollowFeed`
- `NovelBookmarks` → uses `novelBookmarkStore`

### 4. Cleanup (T6)
Deleted 9 dead files including `feedStore.ts`, `novelStore.ts`, `TabFeedPage.tsx`, `NovelFeedPage.tsx`, `Bookmarks.tsx`, `HistoryPage.tsx`, `Feed.tsx`.

### 5. Lazy Activation + Auth Pipeline (T8-related)
- `createTQFeedStore`: `lazy: boolean` + `activate()`/`isActivated`
- **ADR-0041**: `tokenReady` barrier + `authPermanentFailure` — blocks requests before token ready
- Web mode token existence check: login page fires zero API requests
- 400 OAuth → UNAUTHORIZED → retry with token refresh

### 6. Performance (T7)
- LRU tab DOM management: keeps at most 2 tabs' DOM alive
- `createTQFeedStore` `enabled: false` — no auto-fetch at module load
- `setTimeout(0)` instead of `rAF` for data loading

### 7. Root Cause Fix for "Entire Page Invisible"
**Primary fix**: Removed `defaultPendingMs: 0` and `defaultPendingMinMs: 0` from `router.tsx`. TanStack Router's `defaultPendingMs: 0` caused immediate Suspense/pending state on route transition. MatchInner's `createResource(loadPromise)` triggered SolidJS Suspense — with no `defaultPendingComponent`, fallback was `null`, replacing entire HomePage DOM. Sync loaders resolved before 1000ms default threshold, so pending state no longer triggers.

**Secondary**: Merged two HomePage `createEffect`s into one to reduce reactive cascade.
