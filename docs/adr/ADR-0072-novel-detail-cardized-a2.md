# 小说详情页 A2 化（Novel Detail Cardized — A2 Visual Language）

Status: accepted

设置页（ADR-0069）、/me、首页（ADR-0070）、插画详情页（ADR-0071）已先后落地 A2 卡片化视觉语言。小说详情页 `/novel` 仍为旧视觉：顶部栏 `surface-appbar` 毛玻璃、封面信息区通底色块（`NovelCoverHeader` 无圆角无阴影）、底部导航为普通工具条。经 Grill 澄清（用户确认动机 = 封面信息区卡片化 / 阅读工具条与正文区对齐 / 底部导航 A2 化 / 封面内排版细节，范围 = 全页含浮层入口，风格 = A2 卡片语言），决定：

- **顶部栏 A2 化**：`surface-appbar` 毛玻璃条改为 A2 卡片式（与 `/illust` `DetailHeader` 同构：返回 + 「小说《标题》」 + 搜索）。
- **封面信息区 A2 卡片化**：`NovelCoverHeader` 由通底色块改为 A2 卡片（封面图通边 + 渐变 + 标题/作者/系列/标签/统计在卡内，圆角 `--borderRadius2XLarge` + `--elevation2`），标题叠封面的视觉保留。
- **正文区对齐**：正文长文**不套卡片**（阅读区保持纯净排版，背景 `--colorNeutralBackground2`），仅容器/间距对齐 A2。
- **底部导航 A2 化**：上一章/下一章/系列入口改为 A2 卡片条。
- **浮层入口对齐**：阅读设置/翻译/系列/评论入口样式与 A2 一致（浮层本体保持既有功能形态）。

理由：

1. **统一性**：五页已 A2，小说页是长篇内容消费页，封面区与插画信息卡割裂感明显；用户实测前四页后明确要求沿用。
2. **阅读体验**：正文是长文本，卡片容器会破坏连续阅读（跨卡换行、背景跳变）——故正文明确不套卡，A2 只作用于封面信息区/工具条/导航（NN/g 分组扫描结论同 ADR-0069）。
3. **克制**：封面卡片化仅改圆角/阴影/间距令牌，不引入重效果（同 ADR-0070/0071 性能判断）。

Considered Options：

- **A2 卡片语言（顶部栏 + 封面卡 + 底部导航，正文纯净）**：**选定**。
- **正文套卡片**：破坏长文阅读连续性，且虚拟化布局（pretext 测量）在卡片容器内需重算——否决。
- **独立阅读器风格（极简无封面信息）**：丢失小说元信息入口（作者/系列/标签），与已定 A2 体系不统一——否决。

Consequences:

- `NovelCoverHeader` 视觉升级为 A2 卡片后，其调用方（仅 `NovelDetail`）随之统一；`NovelFooterNav` 换 A2 卡片条。
- 正文虚拟化逻辑（`blocksWithHeights`/`virtualLayout`）不变，仅容器样式调整。
- 术语见 `docs/adr/glossary-ui-cards.md`（「小说阅读器 A2 化」）。
