# ADR 0007: 拆分 NovelDetail.tsx 为多个子组件

## 状态

已实现

## 日期

2025-06-22

## 背景

`NovelDetail.tsx` (955 行, 34.6KB) 是项目中最大的文件，处理 10+ 个独立关注点。这违反了单一职责原则，降低了可维护性和 AI 可导航性。

## 分析

文件内部的模块边界：

| 组件/逻辑 | 行号 | 职责 | 是否内联 |
|-----------|------|------|---------|
| NovelImageBlock | 78-144 | 图片块渲染（加载/失败/成功三态） | 内联组件 |
| NovelContentBlock | 200-230 | 文本/图片块分发 | 内联组件 |
| parseProgress/resetProgress | 146-179 | 阅读进度序列化 | 工具函数 |
| 主组件: 数据加载 | 232-351 | 3 层缓存加载 | 主组件 |
| 主组件: 图片尺寸 | 353-395 | 内嵌图尺寸预加载 | 主组件 |
| 主组件: 搜索 | 440-530 | 正文搜索高亮 | 主组件 |
| 主组件: 封面区 | 730-793 | 封面/标题/作者/标签/统计 | 渲染 JSX |
| 主组件: 正文区 | 798-858 | 虚拟滚动文本渲染 | 渲染 JSX |
| 主组件: 底部导航 | 862-913 | 上一章/目录/下一章 | 渲染 JSX |
| 主组件: 模态面板 | 915-944 | 设置/系列/评论/查看器 | 渲染 JSX |

## 决策

1. 提取 `NovelCoverHeader` — 封面图 + 标题 + 作者 + 标签 + 统计行
2. 提取 `NovelFooterNav` — 底部固定导航栏（上一章/目录/显示设置/下一章）
3. 保持 `NovelImageBlock` + `NovelContentBlock` 在主文件中（它们本身已是子组件，且与虚拟布局紧密耦合）
4. 主文件从 955 行减至 ~500 行

## 影响

- 正面：降低文件大小 45%；封面和底部导航可独立测试；AI 搜索 "NovelCoverHeader" 即定位
- 负面：3 个新文件；导入依赖增加
- 风险：中（需确保所有信号和事件处理正确传递）

## 符合原则

- 可维护性：单一职责
- 删除测试：移除封面组件不影响正文渲染
