# ADR-0118: app-lynx 推荐轮播打磨 R2（封面比例显示 / 轮播吸附阈值+fling / 冷启动沉浸骨架 / 标签胶囊行）

- 状态：accepted
- 日期：2026-08-28
- 关联：ADR-0115（推荐轮播）、ADR-0117（CoverImage 深模块）、`packages/app-lynx/CONTEXT.md`（新增 4 词条：封面比例显示 / 轮播吸附阈值 / 沉浸骨架 / 标签胶囊行）、`docs/specs/app-lynx-recommended-carousel-polish-r2.md`
- 来源：`/grill-with-docs` 收敛的四点打磨需求（用户确认），全部落在推荐轮播页，不改数据层（createMixFeed 语义不变）。

## 背景

ADR-0115 单卡轮播 + ADR-0117 图片三态上线后，真机/web 反馈 4 个体验问题：

1. **封面被裁**：滑页封面 `aspectFill` 全屏铺满，宽度虽满但高度被裁切，整图不可见。
2. **翻页手势太重**：吸附判定为「round 最近页」（阈值 = 50% 屏宽）且无 fling 甩动判定，体感「快滑满一整个屏幕宽度才切到下一页」。
3. **冷启动无骨架**：首载只有「加载中…」文字，且冷启动（首帧 token 未恢复、401 补拉）存在无任何占位的空白窗口；spec（app-lynx-recommended-carousel §2.5）承诺的「沉浸卡规格骨架」未落地。
4. **无标签**：滑页信息区只有类型徽章/标题/作者/收藏，不展示作品标签（数据已含 `tags` + `translated_name`）。

## 决策

1. **封面比例显示（cover proportional display）**：推荐轮播封面改为「贴顶、宽满、高按原图比例」显示——不裁切不变形，高度用作品元数据预计算（插画 `width/height`、小说方形封面 1:1），不等图加载；**超高图**（按比例高度 ≥ 滑页可视区高）回退 `aspectFill` 裁切（不溢出、无页内滚动）；小说封面同规则；底部渐变 scrim 信息区保持在屏幕底部（图短时露出 surface 背景）。
2. **轮播吸附阈值 + fling（snap threshold）**：吸附判定从「round 50% 最近页」改为「**1/3 屏宽阈值 + fling 甩动**」——拖过 1/3 松手翻页、未过回弹；快速滑动（速度超阈值）即使未到 1/3 也沿速度方向翻页；上一张/下一张对称生效；吸附动画保留。
3. **冷启动沉浸骨架（immersive skeleton）**：首载（渲染流为空）渲染沉浸卡规格骨架——上部全宽 shimmer 图区 + 底部 scrim 区域文字条，取代「加载中…」文字；触发**不依赖 loading 标志**（冷启动请求前立即出现）；已有数据时刷新不闪骨架；失败换整页错误提示。
4. **标签胶囊行（tag chip row）**：滑页 scrim 区新增标签行（插画 + 小说统一）——M3 assist-chip 形态（同「类型徽章行」），文本 `translated_name || name` 带 `#` 前缀；**最多 3 个，超出折叠为「+N」**，单行不换行；**纯展示不可点**（app-lynx 无搜索路由）。

## 被考虑的方案

- **全屏 `aspectFit`（contain 整图可见）**：竖长图两侧留白，不满足「宽度盛满」。否决。
- **位移放大跟手**（拖 1px 图动 >1px）：引入跟手失真、改触摸映射。否决。
- **只降阈值不加 fling**：快甩短距离仍不翻页，体感提升有限。否决（阈值 + fling 同时做）。
- **标签可点击（跳搜索）**：app-lynx 无搜索路由，需新增页面，范围扩大。否决（纯展示）。
- **骨架沿用「加载中…」文字 / 依赖 loading 标志**：冷启动空白窗口仍在（loading 在首帧 401 路径下可能为 false）。否决。
- **保持全 bleed 沉浸（只调裁切模式）**：不满足「整图可见」诉求。否决（用户确认接受图短时露出背景的布局变化）。

## 后果

**正面**：整图可见不变形；翻页轻快（阈值 + fling）；冷启动无空白占位；滑页信息完整（含标签）。
**负面**：封面比例显示改变滑页布局——图短时下方露出 surface 背景，沉浸感弱于全 bleed 裁切（用户确认接受）；吸附语义变更需更新 `swiperMath` 测试与 spec oracle；新增 2 个展示组件（沉浸骨架 / 标签行）与 3 组纯函数（吸附判定、封面显示推导、标签折叠），需按 TDD 补单测；比例显示与 fling 手感属 Lynx 渲染行为，归 web-core + 模拟器/真机验证闭环。
