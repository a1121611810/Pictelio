# 作品详情页 A2 化（Illust Detail Cardized — A2 Visual Language）

Status: accepted

设置页（ADR-0069）、个人中心（/me）、首页（ADR-0070）已先后落地 A2 卡片化视觉语言。作品详情页 `/illust` 作为内容消费核心页，仍为旧视觉：顶部栏 `surface-appbar` 毛玻璃、图片区紧凑堆叠、信息区扁平列表（作者行/统计/收藏/标签/说明无卡片分组）。经 Grill 澄清（用户确认动机 = 顶部栏/图片区/信息区/整体细节全量对齐，范围 = 全页内容区含浮层入口，风格 = A2 卡片语言），决定：

- **顶部栏 A2 化**：`surface-appbar` 毛玻璃条改为 A2 卡片式（与 `/home` header 同构：sticky 容器页面背景色 + 内部圆角卡片含返回/标题/更多菜单）。
- **图片展示区 A2 化**：多图堆叠每张浮起为 A2 卡片（大圆角 `--borderRadius2XLarge` + `--elevation2` 柔和阴影）；单图封面同卡片化。
- **信息区 A2 卡片化**：作者行 / 统计 / 收藏 / 标签 / 说明重组为 A2 卡片分组（复用 `SettingsCard` 视觉语言）。
- **浮层入口对齐**：评论/举报/动作菜单的触发样式与 A2 一致（浮层本体全屏黑底功能性优先，不强改）。

理由：

1. **统一性**：三页已 A2，详情页是用户点击率最高的内容页，视觉割裂感最强；用户实测前三页后明确要求详情页沿用。
2. **信息层级**：详情页信息密集（作者/统计/收藏/标签/说明/评论），A2 卡片分组（语义分组卡片 + 组头）比扁平列表更易扫描（NN/g cards-component 结论，同 ADR-0069）。
3. **克制**：图片区卡片化仅改圆角/阴影/间距令牌，不引入重效果（同 ADR-0070 性能判断）。

Considered Options：

- **A2 卡片语言（顶部栏 + 图片区 + 信息区全 A2）**：**选定**。
- **图片沉浸优先（大图通边无卡片、信息极简）**：视觉上独立于已定的 A2 体系，且与前三页不统一——否决。
- **混合（玻璃顶部栏 + A2 信息区）**：顶部栏与 /home 已定的 A2 卡片式冲突——否决。

Consequences:

- 详情页浮层（`ImageViewer`/`CommentOverlay`）本体保持全屏黑底（功能性），仅入口与信息区对齐 A2。
- 小说详情页（`/novel`）同类信息区后续沿用本决策（不另立 ADR，见 `glossary-ui-cards.md`「详情页 A2 化」）。
- 术语见 `docs/adr/glossary-ui-cards.md`。
