# B 路径 spike：小说正文 `<list single>` 引擎虚拟化（真机 A/B 对照，2026-09-02）

> 票：#313 原型（父地图 #304；方案选型 #311 的 B 路径）
> **结论：spike 通过**——同文（神国漫游记 25679 字）同深度（18 屏连续滚动）A/B 对照：
> list 版 jank 中位 **8.2%**、内存 **167MB**、P50 10–11ms；现状 scroll-view 版 jank 中位
> **22.6%（11.8/22.6/30.2 递增劣化）**、内存 **288MB**、P50 13–14ms。
> **jank 改善 14pp（远大于 2pp 止损线）、达到 ≤10% 验收线；内存 -42% 且曲线平稳；无白屏回退。**

---

## 1. 方法

- **A/B 同文同深度**：同一部小说（关注 feed「神国漫游记」25679 字）深滚 18 屏后各采样 3 次
  `bench-scroll probe`（单手势 gfxinfo 聚合 jank）+ `dumpsys meminfo`。
- 两版 = ①现状 `scroll-view`（全文一次性渲染，ADR-0109 注释原版）；②spike `list single`
  （段落为 `list-item`，`item-key`/`:key` 双份一致 = `p-<idx>`，`estimated-main-axis-size-px=300`
  估高；头部信息卡为首个 item（`meta`）；尾部「— 完 —」item（`end`）；受限小说不走 list）。
- 附带实验：`:main-thread-bindscroll`（MT 通道）真机派发验证。

## 2. 结果（真机 OPPO R11s 60Hz）

| 指标（深滚 18 屏后） | scroll-view（现状） | list single（spike） |
| --- | --- | --- |
| jank（3 次采样） | 11.8% / 22.6% / **30.2%** | 6.1% / **19.6%** / 8.2% |
| jank 中位 | **22.6%**（递增劣化=H1 签名） | **8.2%** |
| 内存 TOTAL | **287.8 MB** | **167.0 MB（-42%）** |
| P50 / P90 | 13–14ms | 10–11ms |
| 白屏/空白 | 无 | 无 |
| 短篇（5051 字）抽样 | 14.2%（历史基线） | 17.2%（单轮噪声内；短篇节点少，虚拟化收益不显） |

## 3. 解读

1. **spike 达标（用户既定验收线）**：jank ≤10% ✅（8.2%）；≥2pp 改善 ✅（-14pp）；内存曲线
   平稳 ✅（167MB 稳态，#302 正文场景实测排除——list 原生回收在段落 item 上起作用）；
   无首屏/滚动白屏 ✅。
2. **机制印证**：scroll-view 深滚 jank **递增劣化**（11.8→30.2）正是 H1「元素树单调增长」的
   签名；list 版随深度稳定（H1 在正文场景被引擎虚拟化化解——**与列表页（卡片 cell 回收 no-op）
   不同，段落轻文本 item 的回收在真机表现健康**）。
3. **附带重大发现（MT 通道）**：`:main-thread-bindscroll` 在真机 `<list>` 上**正常派发**
   （`[BENCH_MT] scroll fire top=184.66…` 递增实测）——**BT `@scroll` 不派发的盲区被 MT 绑定
   打开**：①追更询问「≥70% 进度」信号可复活（不再只剩到底兜底）；②未来「窗口化/滚动感知」
   类优化的信号源恢复；③顺带坐实 MTS（#313 复核通过）在列表场景的价值扩展。
4. **内容长度校准**：短篇（18 段）下虚拟化收益不显（当前屏文本光栅成本相同）——**B 路径的
   真实收益在长文/深滚动**，与 H1 曲线一致；实施后长文阅读体验改善最大。

## 4. 已知项与实施注意（交接 to-spec）

- `estimated-main-axis-size-px=300` 为粗估：长段（>10 行）与短段混排时滚动条估算有修正抖动；
  实施阶段可按正文平均行高精调（或按段落字数估算），并把「估算漂移」列入 spike 后微调项。
- `item-key` 用稳定 `p-<idx>`（正文段落序固定、无重排场景；页码/进度恢复未实现（lynx 现状），
  后续若做滚动恢复需**锚点 id**（如段落 hash），列入实施议题。
- 已改挂点：`onNovelScrollMT`（MT handler，保留 bench 打印；全量实施时决定是否保留该插桩）。
- 受限小说不经过 list（分支独立），回归清单：追更询问（到底+停留）、评论浮层、系列行、屏蔽/
  举报、译文（无译文功能——app-lynx 无翻译）、`⌄ ∨` 跳转（不存在）。
- 上游跟踪：#302（cell 回收）在正文场景无碍（167MB 且随深度稳定），仍保持跟踪。
