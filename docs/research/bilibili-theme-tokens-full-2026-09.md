### 1.1 `_u` 语义引用：主题不变的两条语义

`map.css` 中 40 条语义有 **2 条**指向 `_u` 层：`--text_white: var(--Wh0_u)`、`--graph_white: var(--Wh0_u)` ✅ [S1]。

| 语义 | 原语 | 定义处 | light 值 | dark 值（经 `dark_all`） | 后果 |
|---|---|---|---|---|---|
| `--text_white` | `--Wh0_u` | **仅** `light_u.css` / `*_all.css` | `#FFFFFF` | `#FFFFFF` | 暗色下仍是纯白 → 彩底按钮文字恒白，设计上正确 |
| `--graph_white` | `--Wh0_u` | 同上 | `#FFFFFF` | `#FFFFFF` | 图表"白"永不翻转 |

**结构缺口澄清（纠正上一轮结论）** ✅ [S5][S7][S8]：`--Wh0_u` 在 `light.css` 与 `dark.css` 中**都不存在**（单文件 grep 命中 0），但这**不是缺陷**：
- 线上 SSR 页面同时加载 3 个文件（`map.css` + `light_u.css` + `light.css`），`--Wh0_u` 由 `light_u.css` 提供 ✅ [S13]
- 切暗色时 JS 只把 `#__css-map__` 的 href 从 `light.css` 换成 `dark.css`，**`light_u.css` 不动** ✅ [S11]
- 结论：`_u` 是**第三层"恒定层"**，设计上就与主题无关。`dark_u.css` 404 属于**合理的产物省略**（暗色下 `_u` 值不变，无需单独文件），而非遗漏。

### 9.2 SSR / FOUC 规避机制 ✅ [S13]

视频页 SSR HTML 中的**三个 link，顺序即优先级**：

```html
<!-- ① 语义别名层：永不换片 -->
<link rel="stylesheet" href="…/bili-theme/map.css"/>
<!-- ② 恒定层（_u）：永不换片 -->
<link rel="stylesheet" href="…/bili-theme/light_u.css"/>
<!-- ③ 主题层：唯一被 JS 换片的节点（带 id，供 getElementById 定位） -->
<link id="__css-map__" rel="stylesheet" href="…/bili-theme/light.css"/>
```

关键设计 ✅：
1. **三个 link 均无 `media` 属性**（实测确认）—— 靠 `href` 换片而非 `media` 查询切换，因此切换是**单次网络请求 + 原位替换**，不需要两套资源同时驻留。
2. **`id="__css-map__"` 只挂在主题层上** —— `map.css` 与 `light_u.css` 是不可变的"骨架"，切主题时它们保持已解析状态，浏览器只需重新解析第 ③ 个文件 → **切换成本最小**。
3. **服务端按 cookie 直出正确的文件名**：SSR 时 `bc()` 读 `theme_style` cookie 直接输出 `light.css` 或 `dark.css`（推断自 `bc()` 实现 + 抓到的是 light ✅[S11][S13]）。**这是「支持SSR」的实质：暗色首屏不闪白**。
4. 兜底：未登录（无 `DedeUserID`）一律 SSR 出 light ✅[S11]。

⚠ 观察到的一个真实缺陷 ✅[S13][S16]：**不同 BV 的视频页 SSR 出的 CSS 路径不一致**——`BV1GJ411x7h7` 输出 `…/static/jinkela/long/video/css/video.<hash>.css`（实测 **404**，`NoSuchKey`），而 `BV1xx411c7mD` 输出 `…/static/jinkela/video/css/video.<hash>.css`（实测 **200**，136,701 B）。同一 hash、两套路径，一条已失效。

## 附：方法学备注

1. **抓取必须带 `--compressed`**：不带时会拿到 gzip 原始字节，`grep` 全部失配（上一轮教训）。
2. **CSS 解析不能用 `([^;]+);`**：`map.css` / `light.css` / `dark.css` 的 `:root` 末条声明无尾随分号，会静默丢失（本轮已修正，导致上一轮"某语义缺 `_rgb` 孪生"的假结论被推翻）。
3. **inline CSS 的 `_rgb` 值带空格**（`--Si8_rgb: 77, 93, 124`）而 CDN 版不带（`77,93,124`），比对前必须**去空白归一**，否则会误报 191 处漂移。
4. **组件令牌提取需防 BEM 误判**：`.card--light:hover` 会被 `--[\w-]+:` 模式误捕为自定义属性；必须要求前置边界为 `{` `;` 空白或行首（本轮据此把首页"154 个局部令牌"修正为 **49 个**）。
