# Spec: 多语言 i18n（简中源 + 英文，双端全量）

> 状态：draft → 待 to-tickets 拆分
> 来源：wayfinder 地图 [#492](https://github.com/a1121611810/Pictelio/issues/492)（六票决议 + 抽取原型实测）
> 基座分支：`feat/i18n-zh-en`（= 原型 `prototype/i18n-extraction` 2b17c1db 转正：双端 i18n 模块 + 三试点文件已落地且门禁全绿）
> 配套规范：[UI 文案风格基线](/docs/style-guides/ui-copy.md)

## 1. 目标

- UI 文案与代码解耦：简中为源语言，新增英文；**UI 语言切换即时生效**（Web 层，不重启）。
- **双端同步全量**：主端 `packages/app` 143 文件 + 副端 `packages/app-lynx` 178 文件（字面量含中文，~4.3k/6k CJK 行，盘点票 #491）。
- 英文译文满足 Apple HIG 风格基线（`docs/style-guides/ui-copy.md`）。

## 2. 非目标（Out of scope，地图已定）

- RTL 语言、Pixiv 内容侧翻译（UP 主生成内容）、`packages/website` 落地页 i18n。
- UI 语言与 Pixiv 内容语言联动（API 保持零语言信号；后续如做需先实证 App-API 对 lang 参数的响应面，另立 effort）。
- 存量中文文案润色（迁移期零行为变更）。

## 4. 架构设计

### 4.1 模块结构（已在原型落地）

```
packages/app/src/i18n/
├── index.ts          # locale signal + settings_language 键 + translator 装配 + t()；导出 Locale/I18nKey/Dict 类型
└── locales/
    ├── zh-CN.ts      # 源语言，静态内联（首帧零闪烁）；导出 I18nKey = keyof typeof zhCN 与 Dict
    └── en.ts         # `as const satisfies Dict`（key 漂移 = 构建失败）；dynamic import 独立 chunk 后台预取

packages/app-lynx/src/i18n/
├── index.ts          # 手写 message 模块：module ref locale + t(key, vars) + {{var}} 插值
└── locales/{zh-CN,en}.ts   # 副端 bundle 小，双语言静态内联（Lynx 动态 import chunk 未验证，如需懒加载另立票）
```

- **t() 契约**：`t(key: I18nKey, args?): string`——字典未就绪窗口回退源语言文案，源也没有回退 key 本身；**恒返回 string，组件零适配**，无空白闪烁、无 Loading 边界需求。
- **语言判定链**（优先级从高到低）：① 手动覆盖（`settings_language` ≠ ""）② 系统语言（**仅经显式注入点读取**：native 侧经桥注入有效 locale——WebView 会异步重置 locale 且 Node≥22 原生暴露 navigator.language=en-US，原型实测；Web dev 以 navigator.language 兜底）③ 兜底 `zh-CN`。**业务代码禁止散读 navigator.language**。
- **设置键**：`settings_language`（string，`""` = 跟随系统，值域 `"" | "zh-CN" | "en"`）。主端走 settings registry `define` + `apply` 钩子联动 locale signal（与 themeStore 同接线法）；`i18n` 模块在 main.tsx 静态导入（define 必须先于 hydrateAll，否则存储值不加载）。WebDAV 备份经 registry `rawValues` 自动收编。
- **副端接线**：lynx settingsStore（手写键模式）持久化 `settings_language`，启动时 `setLocale()`；模块级 ref 在模板/computed 内调用即建立响应依赖，切换即时生效。
- **双端键契约**：key 命名规范 `<域>.<区块>.<语义>` 两端一致；`settings_language` 键名与值域跨引擎逐字一致——按 `webdavSettingsConsistency` differential 模式加契约测试。
- **复数**：zh 单一类，en one/other 两态；手写复数分支函数（如需），不上 ICU。

### 4.2 主端translator 装配（原型已验证）

`translator(() => Dict | undefined, resolveTemplate)` → NullableTranslator；外层包 `t()` 落回退链。en chunk 在模块加载时后台预取（`import("./locales/en")` 失败 `console.warn` 回退源语言，禁静默降级）。

## 5. 迁移策略（to-tickets 的拆分输入）

原则：**每批独立可合入、门禁全绿**；结构改造不混入机械批次。

| 批 | 内容 | 规模（约） | 性质 |
| --- | --- | --- | --- |
| B1 | 错误文案层：`api/client.ts` classifyError/toApiError 的 message **key 化改造**（`ApiError.message` 生成时快照 → 延迟渲染/key 化，双端同构）+ `ErrorDisplay.tsx`/`errorPresentation.ts`（原型已抽展示层） | 结构改造 | 先行，其余批次消费其产出 |
| B2 | settings 域（主端 settingsStore + settings/ 子组件 + lynx settingsStore 相关页） | ~15 文件 | 机械 |
| B3 | routes 层（双端页面骨架文案） | ~38 文件 | 机械 |
| B4-B6 | 主端 components（84 文件分三批，含 home/illust/settings/novel/ui 子目录） | ~84 文件 | 机械 |
| B7 | 主端 stores/utils/primitives/services（~85 文件，多为错误消息与提示） | ~85 文件 | 机械+抽查 |
| B8-B9 | lynx pages/components/utils（~120 文件分两批） | ~120 文件 | 机械 |
| B10 | 日期/数字收敛：8+ 处 `toLocaleDateString("zh-CN")` 收敛为集中 locale 感知格式化层（主端 Intl，Lynx 避 Intl 或 polyfill）+ 原生层字符串盘点（upgrade.html、通知） | 结构改造 | 单独票 |
| B11 | 收尾：回潮门禁启用（AST 扫描测试，白名单清零）、E2E 补齐、抽检 | — | 门禁 |

- 机械抽取按原型操作手册执行：switch→key 映射表 / 直替 + 字典同步；每批跑 `pnpm check:all` + `test:all` + `lint:all`。
- 测试同步原则：断言文案的测试依赖 vitest setup 钉 locale（已落地双端），**期望值改动仅当源文案变化时发生**；禁止顺手改文案（行为变更须单独说明）。

## 6. 测试策略

- **编译期**：`satisfies Dict` 键完备（en 缺 key/多 key = 构建失败）——主防线。
- **运行时**：缺 key 回退源语言 + `console.warn('[i18n]')`（禁静默降级，仓库测试硬约束 #3）。
- **测试确定性**：双端 vitest `setupFiles` 钉 `navigator.language = "zh-CN"`（已落地）；i18n 模块单测覆盖切换/回退（已落地原型）。
- **回潮门禁**（B11 启用）：AST 扫描测试——遍历 `src/**`，剥注释后标 CJK 字符串字面量，`i18n/` 字典、测试文件与显式白名单外报错；随批次进度收紧白名单至零容忍。伪本地化（en-XA）同期评估，不强制。
- **E2E**：agent-browser 加语言切换用例（设置页切 English → 断言 UI 文案变化 + 刷新后保持）；android-e2e 契约不受影响（无原生语言断言）。
- **SolidJS 2 注意**：settings `apply` 钩子的 signal 写入受批处理语义影响，测试断言前 flush（原型已踩，见 #496 报告 §3.1）。

## 7. 翻译生产管线

1. **工具**：自写脚本（LLM API 批量调用）优先——输入=新增/变更 key 的 zh 字面量 + 本基线全文 + 术语表；输出=en 候选。工具化平台（Lingo.dev 类）暂缓。
2. **触发**：B 批实施中随批产出；合入后 zh 字面量变更的 key 走增量重译（脚本 diff 字典）。
3. **人工校对**：按基线 §5 流程（机检 → 术语抽查 → 入库）。
4. **验收条件**：① 基线硬规则零违反 ② 术语表一致 ③ E2E 语言切换用例绿 ④ 英文文案长度回归抽查（按钮/卡片无溢出——每批 review 项，英文平均比中文长 30-50%）。

## 8. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 英文文案变长撑破布局 | 每批 review 截断/换行；Fluent token 字号体系不动；必要时 `max-lines` 截断策略 |
| Lynx 端无 Intl（日期/数字） | B10 集中格式化层规避； Intl polyfill 仅在证明必要时引入 |
| OTA 整包与 per-locale chunk | 选型票 #494 已核：chunk 顺带分发无阻塞 |
| 321 文件长周期迁移中的并行功能开发 | 每批独立合入 + 分域不重叠（ticket 划分按目录域）；`settings_language` 等共享键改动只允许 B2/B10 |
| next 轨道依赖（solid-primitives 3.0.0-next.4） | 精确锁版本；SolidJS 2 stable 后跟进 stable 3.0（#494 已核 monorepo 健康） |
